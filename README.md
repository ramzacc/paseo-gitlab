# GitLab for Paseo

Merge request and issue views for gitlab.com or self-hosted GitLab inside Paseo. See [OVERVIEW.md](OVERVIEW.md) for what it does and how to set it up.

## Install

```bash
paseo plugin add git:ramzacc/paseo-gitlab
```

Then open Settings → Plugins → GitLab and enter your base URL and a personal access token with the `read_api` scope.
